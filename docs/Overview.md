# 项目概述 (Project Overview)

## 1. 游戏简介
一款以柏青哥为原型的2D单人休闲网页游戏，主打高反馈感和物理弹射的随机快感。

## 2. 目标平台
* **Web浏览器：** 主要适配 iOS/Android 竖屏浏览，及 PC 浏览器横屏浏览。

## 3. 核心特色
* **物理真实感：** 真实还原重力、弹性、摩擦力物理反馈。
* **跨平台响应式体验：** 不同设备下的多重布局，无缝切换适配。
* **操作性机制：** 玩家通过右下角竖向手柄进行单轴蓄力，依靠刻度记忆、球种差异与机关布局形成可学习的微操深度。
* **自定义创作：** 首发以内置关卡/场景编辑器服务团队内容生产为主，公开 UGC 上传与分享属于后续阶段。
