# 美术与音频资产规范 (Art & Audio Guidelines)

## 1. 美术规范
* **产出格式要求：** 为保证放大缩小依然清晰，倾向于大范围采用高分辨率的矢量转换图，或标准 2D 序列帧 (Sprite Sheet)。
* **UI 多端自适应：** UI 设计人员需准备“横板”和“竖版”两套独立的排版切图原型。所有底板元素尽可能使用 9-Slice（九宫格）切图格式以支持拉伸不变形。
* **视觉特效 (VFX)：** 在小球碰撞墙壁/机关时需要明确的发光、火花特效；落入奖励槽必须具备强烈的屏幕震动或大范围粒子爆点，极大地增强玩家的中奖刺激感和正向反馈。

## 2. 音效设计要求
* **物理反馈拟音：** 配置多层级、多音高的清脆金属弹击音效。特别是当小球发生高频连续反弹时，物理层应驱动音调递增（Pitch up）的动态系统，创造出“解压感”。
* **交互与情绪音效：** 进入“Fever Time（狂热时刻）”需无缝切换为极具动感的打击乐 BGM；玩家下拉虚拟手柄蓄力时，需要机械齿轮扭转上膛拉拽的强力度音效（Tension up）。
