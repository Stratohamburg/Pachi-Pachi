# 养成与局外成长系统 (Meta-Progression System)

## 0. 版本范围说明 (Release Scope)
本文件同时描述首发成长闭环与后续扩展方向。首发版本以**单人离线、本地持久化**为前提，优先保证成长曲线清晰、资源回收稳定、功能可验证。

* **首发 MVP 必须包含：** 基础天赋树、基础英雄弹珠解锁、本地抽卡、本地碎片升星、少量 Garage 改装位。
* **后续阶段再扩展：** 深层收藏系统、复杂多页改装、联动活动球池、依赖服务端的赛季成长系统。

## 1. 全局天赋树引擎 (The Talent Core)
* **主干设定：** 类似于《Hades》的暗夜之镜。每次在肉鸽模式失败后，玩家将带出一种局外代币“记忆碎片”。以此攀爬局外技能树以抗衡后期的极高难度。
* **物理系天赋树：** 
  * `微观动能`：全局提升小球 2%~10% 的初速度与弹性系数。
  * `引力适应`：稍微延缓关卡环境自带的危险重力影响倍数。
* **经济系天赋树：** 
  * `起步资金`：单局开局获得额外的金币可用于第一层的局内商店。
  * `底力扩容`：永久使玩家每局初始多带入 3~5 颗后备弹珠（极大幅增加容错率）。

### 1.1 首发 MVP 约束
* 首发仅实现 8-12 个可数值验证的节点，不做大型网状天赋盘。
* 天赋效果优先选择可稳定叠加、易于回归测试的数值型增益。
* 任何会改变碰撞规则的高风险天赋，必须在核心手感稳定后再开放。

## 2. 英雄弹珠收集与图鉴 (Gacha & Character Balls)
* **弹珠视为角色 (Hero Balls)：** 游戏不采用单一的制式弹珠，玩家可以通过本地抽卡或获取碎片，解锁不同“英雄弹珠”。每个局内开始时可以编队携带 1~3 种球。
* **英雄弹珠特化设计：**
  * **刺客球：** 体积缩水 30%（更容易穿过缝隙），但具有超高反弹率，每次撞击分值极高。被动技：无视首次落入死槽，重新传送至顶部。
  * **狂战士球（铅球）：** 质量极大，下落极快，反弹弱。被动技：能砸碎所有挡路的玻璃障碍，适合用于开路并打通底层大奖槽。
  * **幽灵球：** 半透明材质，拥有穿透被动（穿透机台的前3根钉子），可完全改变手感。
* **碎片升星系统：** 获取重复的球可转化为碎片。1星到5星之间逐步解锁该球的高级被动天赋（例如3星解锁开局体积微调、5星解锁自带第一次撞击爆破）。

### 2.1 首发 MVP 约束
* 首发只开放 3-5 种差异明确的英雄弹珠，避免养成面过早膨胀。
* 抽卡结果仅落本地存档，不依赖联网账户体系。
* 升星优先解锁数值强化与少量低风险被动，不在首发引入复杂连锁触发。

## 3. 车库与机具改装系统 (Garage & Handlers)
* **改装机具硬件：** 针对发射器本身的强化系统。玩家通过通关章节或成长节点解锁机具外设配件。
* **高精刻度仪 (Precision Scale)：** 允许手柄滑轨上的辅助刻度线变得更加细碎且带有数值标号，还能记录“上一发”力度的拉条残影，极大帮助玩家进行高精度的重复微调。
* **磁性回收器 (Magnetic Drain)：** 为底部死槽加装微弱斥力场，有极低概率将必死的球重新弹回台面上方。

### 3.1 首发 MVP 约束
* 首发仅开放 2-3 个 Garage 槽位，聚焦“蓄力刻度”“容错回收”“初始资源”三类强化。
* 改装效果必须可被 UI 明确展示，避免出现玩家无法感知的隐形收益。
* 复杂材料合成、章节专属配件与多页 Garage 面板属于后续阶段。

## 4. 递延成长项 (Deferred Progression)
以下内容保留为后续阶段，不作为首发阻塞项：

* 大规模收藏图鉴、球体皮肤册、联动限定球池。
* 与赛季、活动或排行榜绑定的成长奖励。
* 需要服务端同步的跨端仓库、限时商店与在线成长事件。
