# 核心玩法与基础循环 (Core Gameplay)

## 1. 核心操作与物理体验 (Core Mechanics & Physics)
* **弹射操作机制 (The Launch)：** 
  * 玩家通过操作位于**屏幕右下角的竖向推拉手柄**进行蓄力。通过手指或鼠标在竖条区域内上下滑动，可以极其精确地微调弹射的**力度**。
  * **固定发射方向：** 发射初始方向由关卡中的发射器朝向定义，玩家在局内不进行连续角度调节，核心学习成本集中在力度刻度、球种手感与机关认知。
  * **无轨迹盲打机制 (No-Trajectory)**：画面上不提供任何抛物线或落点预测。玩家完全依靠操作手柄旁边的**精细刻度尺**来记忆发射力度（例如：“拉到3.5刻度刚好能擦过右上角的金币柱”）。高频的容错尝试和微调是游戏核心的成就感来源。
  * **极限蓄力区间**：蓄力达到90%-100%区间内时，触发手柄视觉震动，在此区间释放有概率触发隐藏的“完美发射(Perfect Launch)”，小球获得起步霸体（不受前三次碰撞的减速影响）。
* **物理反馈系统 (Physics Feedback)：** 
  * 小球具备基础属性：**质量 (Mass)**、**弹性系数 (Restitution)**、**体积 (Radius)**。
  * 机台障碍具备：**摩擦力 (Friction)**、**微反弹**。
  * 碰撞反馈强调“解压感”，连续在局部密集的钉子区域发生高频碰撞时，触发微小的镜头震动(Camera Shake)以及高频清脆的金属音效。

## 2. 机台元素与机关交互 (Board Elements & Mechanics)
为增加柏青哥局内的变化与策略深度，设计多种互动障碍物：
* **普通钉子 (Basic Pins)：** 最基础的碰撞点，产生固定反弹。
* **高弹力柱 (Bumper/Pegs)：** 触碰后不仅反弹，还会给予小球额外动能加成，并高亮发光，每次碰撞加分倍增。
* **黑洞/传送门 (Wormholes)：** 成对出现。进入A点瞬间从B点以原动能射出，改变轨迹。
* **吃分槽 (Drain/Outlane)：** 屏幕最底部两侧的死角，小球落入此区域被消耗，不产生任何奖励。
* **大奖槽 (Jackpot Pockets) 与 老虎机 (Slot Machine)：** 柏青哥核心的“出玉”（赢球）机制所在。大奖槽通常位于底部中心或由重重机关保护的特定区域。当小球落入大奖槽时，立即获得高额底分，并在HUD上触发**老虎机滚动（Slot Machine）**。
  * 若摇出奖励图案，玩家会获得“回血/弹珠续充 (Extra Balls)”（例如直接增加 3-5 颗本波次的剩余发球数），这是维持续航、突破高波次的核心生存手段。
  * 若摇出特殊的“777”图案，将直接强制触发“Fever Time”。
* **玻璃消匿挡板 (Glass Blockers)：** 仅能承受特定次数碰撞后碎裂，玩家需要通过计算角度将其击碎以打开通往大奖槽的隐藏路径。

## 3. 动态事件与心流控制 (Ev/柏青哥大爆发）：** 完美复刻传统柏青哥进入“确变/Rush”状态时的极致视听倾泻。
  * **触发机制：** 方式一为单球在未出局前的有效碰撞持续为 Fever 能量条充能，满条触发；方式二为大奖槽的老虎机摇出“777”大奖直接触发。
  * **表现形式：** 场景暗转，霓虹灯光效全开，BGM切换为动感极强的高BPM电子乐。
  * **核心效果：** 机台顶部的发射口会自动、甚至无视玩家操作地倾泻下大量（如 5-10 颗）多重小球（Multiball），上演纯粹的“弹珠雨”。同时，底部最致命的死角吃分槽（Drain）将临时升起防掉落挡板（保证绝对得分收益），期间每一次碰撞得分乘以极高倍率。Fever 持续数秒或待所有 Fever 产出的衍生球消耗完毕后结束认阈值由全局配置控制。
  * **表现形式：** 场景暗转，霓虹灯光效全开，BGM切换。
  * **核心效果：** 台面上方倾泻下额外 3-5 颗多重小球（Multiball），底部防掉落挡板临时升起（保证绝对收益），每一次碰撞得分乘以 10 倍。

## 4. 首发单局流程与状态映射
为避免玩法规则和实现状态脱节，首发版本的单局循环建议固定为以下页面与状态流：

1. **大厅页 (Lobby)**：玩家选择 `Play` 进入本次 Run。
2. **局内战斗与构筑 (Battle & Build)**：采用线性波次（Waves）推进，进入 `STATE_BATTLE_READY -> STATE_AIMING -> STATE_FLYING -> STATE_SETTLEMENT` 的核心循环。
3. **肉鸽奖励弹层 (Reward Overlay)**：在满足波次完成条件时中断局内流程，弹出三选一界面，玩家可获取新的弹珠或可放置的机台机关（如额外钉子、弹力柱等），并进入 `STATE_PLACEMENT` 放置道具。
4. **局内结束页 (Game Over / Result)**：本次 Run 结束（如分数未达标或球数耗尽），展示局外资源收益并返回大厅。

### 4.1 局内状态对应的玩家行为
* **`STATE_BATTLE_READY`：** 展示当前波次、目标分数和当前阶段可用球数，手柄不可操作。
* **`STATE_PLACEMENT`：** 玩家获得新的局内道具（钉子、机关）后，进入此状态，通过点击/拖拽在机台合法空白区域布置机关。
* **`STATE_AIMING`：** 手柄可交互，**这是玩家在游玩过程中唯一的操作方式**。刻度尺高亮显示，玩家**只能通过控制向下拖拽的距离来影响弹射的力度**，全权交由不同的弹珠属性和自建路线来产生变数。
* **`STATE_FLYING`：** 手柄锁定，核心反馈集中在碰撞、连击、Fever 充能与机关触发。
* **`STATE_SETTLEMENT`：** 显示本球得分、波次目标达成进度以及剩余球数。
* **`STATE_GAMEOVER`：** 结算本次 Run 带出的资源、达成的波次高度和解锁进度。

### 4.2 首发页面必须承载的信息
* **大厅页：** `Play`、`Gacha`、`Meta Tree`、`Settings` 四个固定入口。
* **局内战斗页：** 分数、Combo、Fever 条、波次目标、剩余球数、当前弹珠种类、暂停按钮、手柄。
* **结算页：** 本局总分、推进波次、获得资源、解锁变化、再次开局入口。

## 5. 基础界面原则
详细界面布局请参考独立的 [界面设计规范文档](../UI/Interface_Design.md)。
* **移动端竖屏法则：** 机台占据主视野，右下角划定专属竖向长条的拖动交互区域（手柄），避开底部容易误触的Home指示条区域。
* **桌面端横屏法则：** 以 16:9 画幅为主。机台本身保持竖向比例居中，左右两侧的冗余空间转化为功能看板：左侧展示连击动画与Fever槽，右侧展示本局遗物、倍率与结算相关信息。
