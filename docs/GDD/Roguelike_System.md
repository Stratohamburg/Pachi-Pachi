# 肉鸽单局系统 (Roguelite Run Mechanics)

## 0. 版本范围说明 (Release Scope)
本文件同时描述首发单局循环与后续扩展方向。首发版本以**单人离线、基于波次(Wave)挑战的 Run 闭环**为目标，优先保证机关放置、弹珠切换与难度递增可落地。

* **首发 MVP 必须包含：** 线性波次推进、局内机关放置机制、多种手感弹珠收集与切换、三选一奖励、波次间结算。
* **后续阶段再扩展：** 极端词缀随机、特殊 Boss 机制、周常挑战规则。

## 1. 单局循环与波次推进 (Core Run & Waves)
放弃“杀戮尖塔”式的分支节点地图（不用选路），改为在一张或多张柏青哥机台底层模板上进行**线性波次（Waves）**挑战。
* **波次目标 (Wave Objectives)：** 每个波次存在基础分目标要求和总发球数限制。玩家需要依靠操控手柄的**力度距离**，在剩余球数耗尽前打够分数以进入下一波。
* **难度递增 (Escalating Threat)：**
  * 随着波次推进，目标分数会指数级增长。
  * 底层模板发生扰动：部分区域出现不可触碰的惩罚区，或者吃分死角变宽。

## 2. 局内构筑核心：弹珠与机关放置 (Deck-building via Balls & Pins)
肉鸽要素被高度具象化为两类实体物品，玩家在通过波次后触发“三选一”奖励：

### 2.1 弹珠种类切换 (Ball Types)
玩家可以获得新的弹珠加入本局的“球袋”，在发射前可以切换当前使用的弹珠。不同类型的弹珠拥有完全不同的物理属性手感与被动技能：
* **普通球 (Base Ball)：** 中等质量、中等弹性，手感均衡。
* **重铅球 (Lead Ball)：** 质量极大，难以被弹射，下落极快，不受轻微碰撞的反向阻挡，适合“大力出奇迹”与强制砸穿路径。
* **高弹球 (Bouncy Ball)：** 极高的 Restitution (弹性)，碰撞时容易飞出极高轨迹，适合在开阔地带打连击。
* **魔法球 (Elemental Ball)：** 触发特定的元素效果（如触碰钉子后带电、带火等）。
* **分裂球 (Split Ball)：** 碰撞达到一定次数（如 5 次）后，会分裂成两到三个较小的子球，极速拉升 Combo 但单体得分降低。
* **幽灵球 (Ghost Ball)：** 发射后的前 3 次碰撞视为“穿透”（不反弹直接穿过），适合无视上层障碍直接砸入机台深处的高分槽。
* **膨胀球 (Puffer Ball)：** 每次受到碰撞后体积微增 5%，增加后续碰钉子的概率，但也极易卡在密集的钉阵死角中。
* **磁性球 (Magnetic Ball)：** 飞行轨迹会向最近的金属类型机关产生微弱的“吸附偏移”，极大降低落空的概率，但很难打出直线长传。

### 2.2 局内机关放置 (Board Placement)
玩家获得的不仅仅是被动 Buff，而是可以直接放置在机台上的**实质物理机关**。在波次间隙或获取道具后，进入 `STATE_PLACEMENT` 状态：
* **安置额外机关 (Pin & Prop Types)：**
  * **普通加分钉 (Score Pin)：** 最稳妥的堆料道具，纯粹填充机台空白处，增加碰撞频次。
  * **高弹缓冲柱 (Bumper)：** 极具弹性的蘑菇形柱子，碰撞后会强烈反弹小球并给予高额得分乘区。
  * **属性附魔钉 (Elemental Pin)：** 例如“雷区钉”，球触碰后带电，下一次碰撞立刻引发范围爆破加分。
  * **传送门对 (Wormhole Pair)：** 一次奖励提供一进一出两个通道，玩家可布置“跨空间快车道”，例如底部死角传送到顶部正中央。
  * **克隆漏斗 (Duplicator Gate)：** 带特定朝向的悬空小窄门，球穿过通道时会额外生成 1 颗同速的衍生球。
  * **脆化玻璃跳板 (Glass Platform)：** 能够稳稳接住一次脱轨坠落的小球并轻微弹起，随后立刻碎裂。是救命用的“垫脚防摔板”。
  * **定向风扇/斥力场 (Repel Field)：** 放置后在周围形成一个小范围的推力场，改变路过小球的默认重力下落抛物线。
* **构筑组合配合：**
  * **放置密钉阵 + 更换高弹球**：利用高弹力不断在自定义钉阵中刷 Combo。
  * **放置轨道钉 + 更换重铅球**：铺设倾斜的直线加速轨，让沉重的铅球精确滑入底部大奖槽。
  * **多重克隆漏斗 + 更换分裂球**：造物主爆兵流，满屏小球极速触发全局碰撞特效，彻底压榨得分上限与系统物理演算。

### 2.3 首发 MVP 约束
* 奖励池包含 10-15 种可放置道具及 4-6 种差异显著的弹珠。
* 玩家有且只能通过鼠标/手指拉动发射手柄的**距离**来控制力度，**无法控制角度，只能靠改变选用的弹珠和人为放置钉子路线**来影响最终的下落过程。

## 3. 动态难度阶梯与轮回机制
* **核心循环推进 (The Climb)：** 玩家面临本局固定的得分考核。一旦某一波耗尽发球数仍未达到考核线分数，即 Game Over。
* **资源带出：** 失败后结算局外资源（如记忆碎片、软货币），用于在大厅抽取新的基础弹珠种类或提升基础手柄上限。

## 4. 递延单局项 (Deferred Run Features)
以下内容保留为后续阶段，不作为首发阻塞项：
* 需要专门 UI、回放或服务端规则支撑的挑战玩法。
* 复合环境灾害和高复杂度诅咒体系。
